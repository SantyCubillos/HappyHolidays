<h2>📝 Descripción del Proyecto</h2>
<p align="justify">
<strong>Happy Holidays</strong> es una aplicación web interactiva y completamente dinámica diseñada para crear y compartir felicitaciones personalizadas. Sin necesidad de crear un archivo para cada destinatario, la plataforma genera automáticamente contenido único a través de parámetros de URL. Los usuarios pueden personalizar mensajes con el nombre del festejado y el tipo de celebración, luego compartirlos directamente en WhatsApp o Telegram.
</p>

<h2>✨ Características Principales</h2>
<ul>
  <li align="justify">🎈 <strong>Globos Interactivos: </strong>Diseño visual atractivo con globos animados que flotan en la pantalla.</li>
  <li align="justify">🎯 <strong>Experiencia Táctil: </strong>Compatible con clic (escritorio) y tap (móvil) para explotar globos y revelar mensajes.</li>
  <li align="justify">🔊 <strong>Efectos de Audio: </strong>Sonido realista de explosión de globos para mayor inmersión.</li>
  <li align="justify">📱 <strong>Totalmente Responsivo: </strong>Funciona perfectamente en dispositivos móviles, tablets y computadoras de escritorio.</li>
  <li align="justify">🔗 <strong>URLs Dinámicas: </strong>Genera enlaces únicos personalizados para cada felicitación.</li>
  <li align="justify">📲 <strong>Integración Social: </strong>Compartición directa en WhatsApp y Telegram.</li>
  <li align="justify">🌐 <strong>Sin Backend: </strong>Aplicación completamente cliente (frontend only), fácil de desplegar.</li>
</ul>

<h2>🎮 Experiencia de Usuario</h2>
<ul>
  <li align="justify"><strong>1. Visualización: </strong>Se presentan dos globos animados flotando: uno con el nombre del evento y otro con el nombre del festejado.</li>
  <li align="justify"><strong>2. Interacción: </strong>El usuario puede hacer clic o tocar los globos para explotarlos y revelar el mensaje sorpresa.</li>
  <li align="justify"><strong>3. Revelación: </strong>Al explotar los globos, se escucha un efecto de sonido y se muestra un mensaje personalizado con el nombre del festejado.</li>
  <li align="justify"><strong>4. Personalización: </strong>El usuario puede crear su propio mensaje accediendo al formulario de personalización.</li>
</ul>

<h2>💻 Tecnologías Utilizadas</h2>
<ul>
  <li align="justify"><strong>HTML5: </strong>Estructura semántica de la aplicación, tarjetas y elementos interactivos.</li>
  <li align="justify"><strong>CSS3: </strong>Animaciones de flotación, efectos visuales, diseño responsivo y layout flexible con Flexbox.</li>
  <li align="justify"><strong>JavaScript (Vanilla): </strong>
    <ul>
      <li align="justify">URLSearchParams para capturar y procesar parámetros dinámicos de la URL.</li>
      <li align="justify">Manipulación del DOM para actualizar contenido dinámicamente.</li>
      <li align="justify">Event Listeners para manejo de interacciones del usuario.</li>
      <li align="justify">Web Audio API para reproducción de efectos de sonido.</li>
      <li align="justify">Canvas API para crear efectos de partículas en las explosiones.</li>
    </ul>
  </li>
  <li align="justify"><strong>FontAwesome: </strong>Iconos SVG para botones de redes sociales.</li>
</ul>

<h2>🚀 Cómo Usar</h2>
<h3>Opción 1: Ver un Mensaje Existente</h3>
<ol>
  <li align="justify">Accede a la aplicación en: <a href="https://santycubillos.github.io/HappyHolidays/">🎈 HAPPY HOLIDAYS 🎈</a></li>
  <li align="justify">Visualiza los globos animados flotando en la pantalla.</li>
  <li align="justify">Haz clic o tap en los globos para explotarlos y revelar el mensaje.</li>
</ol>

<h3>Opción 2: Crear un Mensaje Personalizado</h3>
<ol>
  <li align="justify"><strong>Interactúa con la pantalla: </strong>Haz clic o tap en los globos para explotarlos.</li>
  <li align="justify"><strong>Accede al creador: </strong>Haz clic en el botón <strong>"¡Crea y comparte el tuyo! 🚀"</strong> en la sección de mensaje.</li>
  <li align="justify"><strong>Personaliza: </strong>
    <ul>
      <li>Ingresa el nombre del festejado (solo letras, puntos y espacios).</li>
      <li>Selecciona la festividad a celebrar del dropdown.</li>
    </ul>
  </li>
  <li align="justify"><strong>Genera tu enlace: </strong>Haz clic en <strong>"Crear y Compartir 🚀"</strong> para generar el URL personalizado.</li>
  <li align="justify"><strong>Comparte: </strong>Envía el enlace mediante WhatsApp o Telegram usando los botones integrados.</li>
</ol>

<h2>🐛 Solución de Problemas</h2>
<ul>
  <li align="justify"><strong>Los globos no explotan: </strong>Asegúrate de que tu navegador permita interacciones con JavaScript y que no haya conflictos con extensiones del navegador.</li>
  <li align="justify"><strong>Sin sonido: </strong>Verifica que el volumen del dispositivo esté habilitado y que el navegador permita audio.</li>
  <li align="justify"><strong>Formulario no se abre: </strong>Intenta refrescar la página (F5) o vaciar el caché del navegador.</li>
  <li align="justify"><strong>Problemas en móvil: </strong>Asegúrate de estar usando un navegador moderno con soporte para CSS3 y JavaScript ES6+.</li>
</ul>

<h2>♿ Accesibilidad</h2>

<ul>
